🔐 Authentication

POST /auth/login PUBLIC

Authenticate a user and receive a JWT access token for subsequent API calls.

Client
POST /auth/login
→
FastAPI
verify_password()
→
Profiles
SELECT user
→
JWT Token
create_access_token()
→
Response
200 OK + token

📤 Request Body

{
  "email": "user@example.com",
  "password": "securepassword123"
}

📥 Response (200 OK)

{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "expires_in": 86400,
  "user": {
    "id": "uuid",
    "email": "user@example.com",
    "name": "John Doe",
    "role": "customer"
  }
}
POST /auth/register PUBLIC

Register a new customer account with email verification.

Client → POST /auth/register {name, email, password} FastAPI receives
API → Check email uniqueness No duplicate?
API → hash_password(bcrypt) Hashed
DB → INSERT INTO profiles User created
API → create_access_token() JWT issued
Client ← 201 Created + token + user ✅ Authenticated

Client

→
Response

📦 Quotes

POST /quotes/calculate AUTH

Calculate a price estimate without persisting a quote. Returns instant pricing breakdown.

Client
POST {origin, dest, mode, weight}
→
Pricing Engine
estimate_price()
→
Calculation
base + (kg × rate) + (cbm × rate)
→
Response
200 {amount, breakdown}

📤 Request

{
  "origin": "Shanghai",
  "destination": "Los Angeles",
  "mode": "sea",
  "weight": 5000,
  "volume": 20.5,
  "cargo_type": "general"
}

📥 Response (200)

{
  "amount": 2500.00,
  "currency": "USD",
  "breakdown": {
    "base": 80.0,
    "per_kg": 0.4,
    "per_cbm": 35.0
  }
}
POST /quotes AUTH

Create a new freight quote request with auto-pricing.

Client → POST /quotes {origin, dest, mode, weight} FastAPI receives
API → estimate_price(mode, weight, volume) Auto-calculated amount
API → generate_ref("QT") QT-ABC123
DB → INSERT INTO quotes Quote created
DB → INSERT INTO shipments Shipment auto-created
DB → INSERT INTO invoices Invoice auto-created
Client ← 201 + quote + linked shipment + invoice ✅ Complete
POST /quotes/{id}/approve AUTH

Accept a quote (customer accepts own, staff can accept any).

Client
POST /quotes/{id}/approve
→
RBAC Guard
assert_owner_or_staff()
→
Quotes
UPDATE status='accepted'
→
Response
200 + updated quote

💰 Finance

POST /finance/payments AUTH

Create a payment against an invoice. Automatically marks invoice as paid.

Client → POST /finance/payments {invoice_id, amount} FastAPI receives
API → Verify invoice exists + ownership Authorized?
API → generate_ref("PAY") PAY-XYZ789
DB → INSERT INTO payments Payment recorded
DB → UPDATE invoices SET status='Paid' Invoice marked paid
Client ← 201 + payment record ✅ Complete
GET /finance/profit-loss FINANCE

Get profit/loss summary with revenue, expenses, and margin percentage.

Finance
GET /finance/profit-loss
→
RBAC Guard
require_roles(FINANCE)
→
Invoices
SUM total WHERE status='Paid'
→
Expenses
SUM amount
→
Calculate
profit = revenue - expenses
→
Response
200 {revenue, expenses, profit, margin}
